# IBM Data Science Capstone

Final project repository for the IBM Data Science Professional Certificate.

## Project overview

This project analyzes historical automobile sales data, explores sales patterns during recession and non-recession periods, builds interactive visualizations, and evaluates a predictive classification model.

> **Note:** Results, charts, model metrics, and conclusions will be added only after the corresponding notebooks and assignment outputs are reviewed. No results are fabricated in this repository.

## Repository structure

```text
.
├── data/                 # Source datasets (check course sharing rules before committing)
├── notebooks/            # Completed course notebooks
├── dashboard/            # Plotly Dash application
├── visualizations/       # Exported charts and dashboard screenshots
└── presentation/         # Final presentation source and PDF
```

## Project workflow

1. Data collection
2. Data wrangling and preparation
3. Exploratory data analysis (visualization and SQL)
4. Interactive map with Folium
5. Interactive dashboard with Plotly Dash
6. Predictive analysis and model evaluation
7. Final presentation and conclusions
