# IBM Applied Data Science Capstone — SpaceX Falcon 9

This repository contains the **SpaceX Falcon 9 first-stage landing prediction capstone**. The project studies launch outcomes, launch sites, payloads and booster reuse, then builds an educational binary classifier for first-stage landing success.

> The previous automobile-sales materials were from the wrong assignment. The correct SpaceX project is now organized under `spacex/`; use the SpaceX PDF and artifacts generated by the `SpaceX Capstone` workflow.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r spacex/requirements.txt
python spacex/analysis.py
python spacex/build_presentation.py
python spacex/dashboard.py
```

The analysis downloads the IBM Skills Network SpaceX course dataset (with a public GitHub mirror fallback), creates EDA figures, SQL outputs, a Folium launch-site map, model metrics, and the presentation PDF.

## Main deliverables

- `spacex/Capstone_Presentation.pdf` — final presentation (generated)
- `spacex/analysis.py` — data preparation, EDA, SQL, mapping and predictive analysis
- `spacex/dashboard.py` — interactive Plotly Dash application
- `spacex/analysis_queries.sql` — reproducible SQL queries
- `spacex/outputs/` — generated results (local/Actions artifact)

## Data and limitations

The project uses the IBM Skills Network educational Falcon 9 dataset, based on historical launch records. The commonly used capstone subset contains 90 Falcon 9 launches. It is a small, historical teaching dataset—not a live operational feed and not a guarantee of future landing outcomes. Model metrics are specific to this sample and split.

Data source: [IBM Skills Network dataset](https://cf-courses-data.s3.us.cloud-object-storage.appdomain.cloud/IBM-DS0321EN-SkillsNetwork/datasets/dataset_part_2.csv); public mirror: [Abhigyan-RA/SpaceX-capstone](https://github.com/Abhigyan-RA/SpaceX-capstone).
